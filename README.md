# COBOL Learning Labs on z/OS

Practical COBOL learning repository built on IBM z/OS ADCD 1.11.

This repository focuses on learning the COBOL language itself through small, reproducible labs. Environment provisioning and deeper COBOL/DB2/CICS integration are covered separately in the companion portfolio `mainframe-cobol-db2-cics-devops-lab`.
